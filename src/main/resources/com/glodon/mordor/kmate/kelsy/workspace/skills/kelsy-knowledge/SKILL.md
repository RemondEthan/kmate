# Kelsy 知识库

加载后严格按本文操作。磁盘上的 Markdown 是唯一真相，你的记忆不是。

## 库长什么样

| 路径 | 角色 | 你怎么碰 |
|---|---|---|
| `MEMORY.md` | 短索引，每轮已在上下文里。只留「现在仍为真」 | 只用 `memory_save` |
| `memory/YYYY-MM-DD.md` | 当日流水 | 只用 `memory_save` |
| `knowledge/KNOWLEDGE.md` | 专题目录（路径 + 一句话） | 文件系统工具 |
| `knowledge/people/` `projects/` `playbooks/` `inbox/` | 常青正文 | 文件系统工具 |
| `AGENTS.md` | 人设摘要 | 不要改 |
| `sessions/` | 原始聊天 | 不要当已归档事实 |

`memory_save` **只写** `MEMORY.md` 和当天日记，**不写** `knowledge/`。

禁止 `write_file` / `edit_file` 改 `MEMORY.md` 或 `memory/`。

## 何时归档

用户明确要记，或聊到值得以后问的：决定、偏好、人名+关系、日期、进展、承诺。

闲聊、情绪、一次性寒暄：不存。

## 怎么写一条（为半年后能搜到）

`memory_save` 的每条必须**自含**，一条一事：

- 有 **ISO 日期**（`YYYY-MM-DD`，不知日则 `YYYY-MM`）
- 有以后会用来问的 **专名**（人名、项目、公司）
- 不写「如上」「那个方案」「他」

好：`- 2026-03-15 与张三敲定评审方案，周五评审`

坏：`- 敲定了方案`（半年后问「张三」或「半年前」都对不上）

同一主题第三次出现：用文件系统工具写入 `knowledge/` 对应目录，在 `KNOWLEDGE.md` 加一行目录，`MEMORY.md` 只留指针（仍用 `memory_save` 写指针）。专题页标题和首段也要含专名和日期。

`MEMORY.md` 目标 2–4KB。膨胀了按用户 `/tidy` 指令收瘦：过时流水只留在日记或专题，索引只留仍为真的短句。

## 怎么查（尤其是半年前）

半年前的日记**不在**本轮自动注入里。只看 `MEMORY.md` 会漏。按顺序做，不要跳：

1. **把相对时间换成日期窗口**（以用户说「今天」的日历为准；没有则用系统日期）
   - 昨天 → 当天 ±0
   - 上周 → 过去 7 天
   - 上月 / 本月 → 日历月
   - 半年前 → `(今天 − 6 个月)` 所在月，再各扩一个月  
     例：2026-09-02 → **2026-02-01～2026-04-30**
   - 「2026年3月」→ 2026-03-01～2026-03-31
2. **先 `memory_get` 窗口内的** `memory/YYYY-MM-DD.md`（有文件才读，不要猜内容）
3. **再 `memory_search`** 用户话里的专名（张三、项目名）。防记在相邻几天
4. **再看** 已注入的 `KNOWLEDGE.md` / 知识路径清单，对得上的专题 `read_file` **指定路径**
5. 禁止把整个 `knowledge/` 读进回复

没有日期、只有专名：从步骤 3 开始，必要时再扩大 search。

## 怎么答

- 只用刚读到的原文，改写可以，事实不能加。
- 每条关键事实写 **`来源：相对路径`**（如 `来源：memory/2026-03-15.md`）。
- 多条矛盾：都列出，标日期，让用户看，不要私自挑一条。
- 窗口内无文件且 search 为空：**只说**「知识库这段时间没有归档」，**不许编**，不许用会话印象顶上。
- `sessions/` 里有、库里没有：当作没归档，不要说成已记录的事实。

## 客户端斜杠（你看到的是改写后的中文指令）

| 用户打的 | 你收到的意图 | 你做 |
|---|---|---|
| `/note …` | 强制归档这段话 | 按「怎么写一条」`memory_save`，回复里写清写到了哪些路径 |
| `/today` | 汇总今天已归档 | search/get **今天**的日记和索引，列表 + 来源 |
| `/tidy` | 收瘦索引 | 只许 `memory_save` 调整索引；过时内容指向日记或专题；不是清空 |
| `/find …` | **不会发给你** | 用户在本地验收检索。你不必执行 `/find` |

`/note` 或主动 `memory_save` 之后，回复必须出现实际路径（`MEMORY.md` 和/或 `memory/YYYY-MM-DD.md`，升格则加上专题路径）。
